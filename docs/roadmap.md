# Project scope and roadmap

## Alpha RC v0.1.0 — included

Shared shopping list, hidden quantity-one behavior, strikethrough checking, Done/clear completed, real-time notifications, any-store profiles with browser-specific selection, walking route, category keyword memory, product exceptions, and JSON store-map import/export. Docker Compose, persistence, documentation, and tests included.

## Candidate future enhancements (not implemented)

- Better duplicate/quantity conflict resolution under simultaneous edits.
- Usability polish after real shopping trips (especially one-handed mobile use).
- More detailed first-run guided store setup and screenshot-to-aisle recognition.
- Installable offline-capable PWA with queued offline editing (not just a web manifest).
- More convenient product/category training and conflict handling on imports.
- Optional automatic product-to-aisle lookup via a third-party API, never a required paid service.
- Community-shared store layouts and a searchable/downloadable catalog *if* adoption warrants it.
- Explicit account/proxy hooks for adopters who desire authentication, while preserving accountless core operation.

## Explicitly out of scope for the initial alpha

Separate shopping lists by person or retailer, individual user identities, purchase attribution, advanced quantities/units (ounces/pounds), retailer inventory, payments, and a hosted cloud SaaS service.

Community feedback should focus on actual shopping flow and installation ease, not premature integrations.
